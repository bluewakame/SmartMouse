SmartMouse Receiver v0.5.0
==========================

これは、iPhoneをWindows PCの緊急用マウス・キーボードとして使うための
Windows側アプリです。Pythonのインストールは不要です。


接続方法
--------

1. ZIPを右クリックして「すべて展開」を選びます。
2. 展開したフォルダーの SmartMouseReceiver.exe を開きます。
   起動するとQRコード画面が開き、タスクトレイに常駐します。
   ※ SmartMouseReceiver.exe は _internal フォルダーと同じ場所に置いたまま
     使ってください。exeだけを別の場所へ移すと起動しません。
     フォルダーごと移動するか、ショートカットを作成してください。
3. Windows Defender Firewallの確認が出たら、
   「プライベート ネットワーク」を許可してください。
4. QRコード画面のQRコードを、SmartMouse iPhoneアプリで読み取ります。
5. iPhoneアプリに「接続済み」と表示されたら操作できます。

iPhoneとWindows PCは同じWi-FiまたはLANへ接続してください。
QRコードには起動ごとに変わる一時認証情報が含まれます。
Receiverを再起動した場合は、新しく表示されたQRコードを読み直してください。


QRコードで接続できない場合
----------------------------

1. iPhoneアプリ右上の設定を開きます。
2. 「QRコードを読み取って接続」を選び、もう一度読み取ります。
3. それでも接続できない場合は、Receiver画面に表示された
   ws:// で始まる接続先を設定画面へ入力してください。
4. QRコード画面を閉じた場合は、タスクトレイのSmartMouse Receiverアイコンを
   右クリックして「QRコードを表示」を選んでください。


必要な環境
----------

- Windows 10 / Windows 11（64bit）
- SmartMouse iPhoneアプリ
- iPhoneとWindows PCが同じWi-Fi/LANに接続されていること


よくある注意
------------

- 署名なしのexeではSmartScreenの警告が出ることがあります。
  信頼できる配布元から入手した場合のみ実行してください。
- ウイルス対策ソフトが誤検知した場合は、CHECKSUMS-SHA256.txt の値と
  配布元が公開しているハッシュが一致しているか確認してください。
  一致していれば改ざんはされていません。
- 会社、学校、ホテル、公共Wi-Fiでは端末同士の通信が遮断され、
  iPhoneからPCへ接続できない場合があります。
- 8000番ポートを別のアプリが使用していると起動できません。
- VPNを利用している場合は、一度OFFにして試してください。
- 管理者権限のアプリを操作する場合は、Receiverも
  「管理者として実行」する必要がある場合があります。


終了方法
--------

画面を閉じてもReceiverは右下のタスクトレイで動作を続けます。
完全に終了する場合は、タスクトレイのSmartMouseアイコンを右クリックして
「終了」を選びます。


自動起動
--------

Receiver画面の「Windowsへのサインイン時に自動で起動」にチェックを入れると、
次回からWindowsへのサインイン後に自動で接続待機を開始します。


ログ
----

問題が起きた場合の詳しい記録は、次の場所に保存されます。
%LOCALAPPDATA%\SmartMouse\receiver.log


バージョン確認
--------------

受信機の動作確認は、Windowsのブラウザーで
http://127.0.0.1:8000/health を開きます。
「status: ready」とバージョンが表示されれば正常です。


インストーラー版
----------------

インストーラー版では、デスクトップショートカット、自動起動、
プライベートネットワーク用ファイアウォール規則、アンインストールを
セットアップ画面から設定できます。
