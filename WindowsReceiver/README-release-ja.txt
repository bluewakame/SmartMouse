SmartMouse Receiver v0.5.4
==========================

これは、スマホを Windows PC の緊急用マウス・キーボードとして使うための
Windows側アプリです。Python のインストールは不要です。

スマホ側に入れるものはありません。標準のカメラでQRコードを読むと
ブラウザが開いて、そのまま操作できます。iPhone でも Android でも使えます。
（SmartMouse iPhone アプリをお持ちの場合は、同じQRコードで接続できます）


安全に使うために（必ずお読みください）
--------------------------------------

このアプリとスマホの通信は暗号化されていません。
想定しているのは「自分の家のWi-Fiで、自分のPCを操作する」ことだけです。

- 自宅など、繋いでいる人を自分で把握できるWi-Fiでだけ使ってください。
  社内、学校、カフェ、ホテル、空港、寮などの共有Wi-Fiでは、同じ
  ネットワークにいる第三者に通信を読み取られる可能性があります。
- パスワードやクレジットカード番号は送らないでください。
  スマホ側の「文字入力 → 送信」で送った内容は、そのまま流れます。
- 使い終わったらReceiverを終了してください。
  合言葉は起動するたびに新しくなり、古い合言葉は使えなくなります。
  これが最も確実な遮断方法です。
- QRコードには合言葉が含まれます。画面共有や配信の最中に
  表示したままにしないでください。

合言葉を知っている端末は、このPCのマウス、キーボード、クリップボードを
自由に操作できます。

- 他人のPCで起動しないでください。
  このソフトは、起動したPCを別の端末から操作できるようにするものです。
  持ち主の同意なく他人のPCへ入れて使うことは、不正指令電磁的記録に関する罪
  などに問われる可能性があります。


身に覚えのないこのソフトが動いていたら
----------------------------------------

自分でインストールした覚えが無いのにこのソフトが動いている場合は、
第三者があなたのPCを操作できる状態になっている可能性があります。
次の手順で止めてください。

1. 画面右下のタスクトレイにあるSmartMouseのアイコンを右クリックし、
   「終了」を選びます。これで接続はただちに切れます。
   （アイコンは接続中はオレンジ色、待機中は緑色です）

2. Windowsの「設定」→「アプリ」→「スタートアップ」を開き、
   SmartMouse Receiver が有効になっていればオフにします。

3. インストールした覚えが無い場合は、アプリの一覧から
   SmartMouse Receiver をアンインストールしてください。
   ZIPを展開しただけの場合は、そのフォルダーごと削除します。

なお、このソフトはスマートフォンが接続した時点でWindowsの通知を出します。
通知が出ていないのに動作している場合でも、上の手順で停止できます。


接続方法
--------

1. ZIPを右クリックして「すべて展開」を選びます。
2. 展開したフォルダーの SmartMouseReceiver.exe を開きます。
   起動するとQRコード画面が開き、タスクトレイに常駐します。
   ※ SmartMouseReceiver.exe は _internal フォルダーと同じ場所に置いたまま
     使ってください。exeだけを別の場所へ移すと起動しません。
     フォルダーごと移動するか、ショートカットを作成してください。
3. Windows Defender Firewallの確認が出たら、
   「プライベート ネットワーク」を許可してください。
4. スマホの標準のカメラアプリでQRコードを写します。
   画面に出るリンクをタップすると、ブラウザが開きます。
5. 「接続済み」と表示されたら、画面をなぞって操作できます。

スマホとWindows PCは同じWi-FiまたはLANへ接続してください。
QRコードには起動ごとに変わる合言葉が含まれます。
Receiverを再起動した場合は、新しく表示されたQRコードを読み直してください。

> ホーム画面に追加すると、アドレスバーの無い全画面で使えます。


QRコードが読み取れない場合
----------------------------

QRコードの下に、同じ内容がURLの文字で表示されています。
これをスマホのブラウザに直接入力しても接続できます。

    http://（PCのIPアドレス）:8000/?token=（合言葉）

それでも繋がらないときは、次を確認してください。

1. スマホとPCが同じWi-Fiにいるか（ゲストWi-Fiは端末同士の通信が
   塞がれていることがあります）
2. QRコード画面を閉じた場合は、タスクトレイのSmartMouse Receiverアイコンを
   右クリックして「QRコードを表示」を選ぶ
3. VPNを使っている場合は、一度OFFにする

SmartMouse iPhoneアプリを使う場合は、標準のカメラではなく、
アプリ内の「QRコードを読み取って接続」から読み取ってください。
QRコードの下に出ている「手入力用:」の ws:// で始まるアドレスも使えます。


必要な環境
----------

- Windows 10 / Windows 11（64bit）
- ブラウザの入ったスマホ（iPhone / Android のどちらでも可）
- スマホとWindows PCが同じWi-Fi/LANに接続されていること

SmartMouse iPhoneアプリは必須ではありません。


よくある注意
------------

- 署名なしのexeではSmartScreenの警告が出ることがあります。
  信頼できる配布元から入手した場合のみ実行してください。
- ウイルス対策ソフトが誤検知した場合は、ダウンロードしたZIPのハッシュが、
  配布元のReleaseページに表示されているSHA-256と一致するか確認してください。
  PowerShellで次のように調べられます。
      Get-FileHash .\SmartMouseReceiver-v0.5.4.zip -Algorithm SHA256
  一致していれば改ざんはされていません。
- 会社、学校、ホテル、公共Wi-Fiでは端末同士の通信が遮断され、
  スマホからPCへ接続できない場合があります。
- 8000番ポートを別のアプリが使用していると起動できません。
- VPNを利用している場合は、一度OFFにして試してください。
- 管理者権限のアプリを操作する場合は、Receiverも
  「管理者として実行」する必要がある場合があります。

終了方法
--------

画面を閉じてもReceiverは右下のタスクトレイで動作を続けます。
完全に終了する場合は、タスクトレイのSmartMouseアイコンを右クリックして
「終了」を選びます。


自動起動
--------

Receiver画面の「Windowsへのサインイン時に自動で起動」にチェックを入れると、
次回からWindowsへのサインイン後に自動で接続待機を開始します。


ログ
----

問題が起きた場合の詳しい記録は、次の場所に保存されます。
%LOCALAPPDATA%\SmartMouse\receiver.log


バージョン確認
--------------

受信機の動作確認は、Windowsのブラウザーで
http://127.0.0.1:8000/health を開きます。
「status: ready」とバージョンが表示されれば正常です。


インストーラー版
----------------

インストーラー版では、デスクトップショートカット、自動起動、
プライベートネットワーク用ファイアウォール規則、アンインストールを
